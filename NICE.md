## Product
- One-click launch of a provider session with an explicit personal/work profile.
- Project detection from Git remotes, directory location, WSL distro, and workspace metadata.
- A “why is this credential being used?” explainability view.
- Safe cross-machine sync of metadata only, with secrets remaining in platform stores.

## Integrations
- Zed, Claude Code, Codex, OpenCode, Copilot, and terminal/TUI launch profiles.
- GitHub and Bitbucket identity/account switching.
- WSL distro-specific provider environments.
- Optional OpenRouter/Slaygent routing status and usage dashboard.

## Tech & meta
- Native Windows tray app with quick profile switching.
- Electron utility-process or sidecar for WSL integration.
- Agent-readable local status API/MCP server, strictly read-only by default.
- Pluggable provider adapter SDK for community integrations.
